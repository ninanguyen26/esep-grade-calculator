# ESEP Grade Calculator

This library is a simple utility to calculate your grades from three categories: assignments, exams, and essays.

Runtime requirements:
Golang 1.24+

Quick Start

```
git clone https://github.com/<username>/<repo-name>
cd <repo-name>
```

Run unit tests:

```
cd grade_calculator/
go test ./...
```

Run unit tests with code coverage:

```
cd grade_calculator/
go test -coverprofile=coverage.txt ./...
```
